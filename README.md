# BCA Study Material Website

## About

This project is a study material website for Bachelor of Computer Applications (BCA) students. The goal is to create a well-organized platform where students can easily find semester-wise study resources and important academic information.

The project is currently in Phase 1 of development and focuses on building a semantic, accessible, and responsive website using HTML and CSS before adding any JavaScript functionality.

---

## Why I Am Building This

As a BCA student, I found it difficult during my first year to know where to find reliable study material and understand how to begin preparing for each semester. This project is my attempt to solve that problem by creating a website that can help future BCA students access resources in one organized place.

At the same time, this project is helping me learn professional frontend development by applying best practices while building a real-world website.
